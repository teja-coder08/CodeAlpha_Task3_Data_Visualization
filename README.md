# CodeAlpha Internship – Task 3: Data Visualization

## Project Overview
This project uses Python to analyze retail sales data and create visualizations that help identify business insights.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Visual Studio Code

## Dataset
The dataset contains 20 retail orders, including product categories, regions, sales, and profit.

## Key Results
- Total Sales: 301,500
- Total Profit: 48,320
- Best-Selling Category: Electronics
- Missing Values: 0

## Visualizations
1. Sales by Product Category
2. Sales Distribution by Region
3. Sales vs Profit Scatter Plot
4. Retail Sales Analysis Dashboard

## How to Run
Install the required libraries:

`pip install -r requirements.txt`

Run the Python program:

`python task3_visualization.py`

## Output
The output folder contains four chart images and a category summary CSV file.

## Conclusion
This project demonstrates how data visualization transforms raw data into meaningful insights for business decision-making.
